# 控件主题统一实施与验证

## 范围与设计

- 需求：按钮以及滑块的风格与背景统一。
- 版本：0.10.2；变更说明见 `CHANGES_V30.md`。
- 实现：`src/controls.css`；入口 `src/main.ts` 在 `src/style.css` 之后导入。
- 使用现有主题的 surface、text、border、accent 变量，不新增主题，不修改业务行为和控件尺寸。
- 主区域使用主题面板色；账号侧栏、状态侧栏、标题栏映射局部控件变量，派生色在各作用域重新计算。
- 按钮使用低饱和背景与细边框；主操作和危险操作保留不同语义色。开关通过位置和主题色区别状态，滚动条轨道透明，滑块使用区域文字色的半透明派生色。
- 覆盖 Element Plus 普通/主操作/语义/plain/text/link 按钮、分段按钮、开关和滚动条，以及原生快捷工具栏按钮。为 Element Plus slider 配套样式，但当前项目没有实际使用 el-slider。
- 保留禁用、悬停、按下、键盘焦点、减少动画设置及刻意隐藏的滚动条。

## 根因

1. 全局主题只映射了部分 Element Plus 变量；深色侧栏继承根部浅色控件变量。
2. primary 浅色阶固定与纯白混合，不适合深色主题。
3. 原生工具栏使用固定白色前景和反差背景、阴影；开关滑块及部分填充/禁用状态仍采用库默认色。
4. Element Plus 边框简写变量在根部计算，侧栏需一并重设，避免分段按钮残留浅色边框。
