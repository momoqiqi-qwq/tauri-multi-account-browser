### 踩过的三个坑（本机环境专属）
1. Git Bash 的 `/usr/bin/link.exe`（GNU coreutils）排在 MSVC link 前面 →
   报 `link: missing operand after '\377\376'`。
2. 只修 PATH 仍不够 → `LNK1181: 无法打开输入文件 "OleAut32.lib"`，
   必须再设 `LIB` 指向 MSVC lib + Windows SDK 10.0.26100.0 的 um/ucrt x64。
3. 用 `cmd //c` 调 vcvars64.bat 不可行：`//c` 会被 MSYS 路径转换吃掉，变成交互式 cmd；
   `cmd /c "带空格路径"` 引号也被吞。PowerShell 工具禁止 cmd.exe，
   且 npm.ps1 包装器有 `$LASTEXITCODE 未设置` 的报错。
   → 结论：别折腾 vcvars，直接注入 PATH + LIB 最省事。
