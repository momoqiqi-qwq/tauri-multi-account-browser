## 环境坑（本次新踩，已写进 skill）

- **vite dev server 只监听 `[::1]`**：`curl 127.0.0.1:1433` 连接被拒（exit 7），要用 `localhost`。
- **沙箱里 curl 默认走 HTTP 代理**，本地端口返回 502，必须加 `--noproxy '*'`。
- 长 `sleep` 轮询循环（`for i in $(seq 1 20); do … sleep 1; done`）会被 SIGTERM 直接砍掉。
- 预览入口若让 `visible` 初始为 `true`，组件里 `watch(visible)` 不会触发，表现为
  「弹窗打开了但列表是空的」。必须先 `false`、挂载后再置 `true`。
- 无头 Chrome 的 `--user-data-dir` 常被残留进程占用，删除失败（`.mut/chrome-run` 216MB 没删掉）。

### 前端 CDP 验证新踩的坑（已补进 skill `vite-component-cdp-probe`）

- **Chrome 继承 shell 的 `http_proxy`**，连 `localhost` 也走代理 → `chrome-error://chromewebdata/`；
  必须加 `--no-proxy-server`。
- **`DevToolsActivePort` 可能没生成**（`--user-data-dir` 目录是空的），改从起 Chrome 的后台任务
  stderr 读 `DevTools listening on ws://127.0.0.1:<port>`。
- **`preview/` 会被别的会话整目录删掉** → vite 静默 fallback 到根 `index.html`（`document.title`
  变成根页面标题、目标元素 0 个）。本会话改用根 `dock-preview.html` + `.mut/dock-entry.ts`，
  用完把 html 移进 `.mut/`。
- **CDP `returnByValue` 序列化不了 Vue `ref`（Proxy）** → `clicks.includes is not a function`；
  记录型数据用普通数组，或探针侧 `JSON.parse(evaluate('JSON.stringify(...)'))`。
- 收尾用 CDP `Browser.close` 关浏览器，比 `taskkill` 干净（MSYS 的 `$!` 不是 Windows PID）。
